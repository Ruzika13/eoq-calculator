⚙️ About This Toolkit

A collection of interactive Industrial Engineering tools built for students, analysts, and supply chain professionals.

This project was created as a hands‑on portfolio to demonstrate Operations Research, Supply Chain, and Manufacturing Analytics concepts in a fully browser‑based, zero‑install format.

🔧 Built with: HTML, CSS, JavaScript
📈 Hosted on: GitHub Pages (free, permanent)
🧠 Designed for: quick, intuitive calculations without spreadsheets.

What you’ll find here:

  • EOQ & EPQ – optimal ordering / production quantities
  • M/M/1 Queue – steady‑state waiting metrics
  • Flow Shop Scheduler – Johnson’s rule & Gantt charts
  • Linear Programming – product mix optimization
  • Inventory Simulation (s,S) – daily stock modelling
  • Break‑Even Analysis – cost‑revenue breakeven
  • Learning Curve – Wright model time estimation
  • ABC Analysis – Pareto inventory classification
